# Frontend Questions for Saturday

These questions aim to expose currently unknown requirements that impact the frontend and user experience.

## Users/Roles
- Are there specific roles beyond Player and Organizer (e.g., League Captain, Super Admin)?
- Should players be able to form their own doubles teams during signup, or does the system handle this later?

## Seasons & Leagues
- Is there a strict cut-off time for season registration, and who enforces it?
- Can a league belong to multiple seasons, or does a new one need to be created each time?

## Formats & Categories
- Are there specialized formats outside of the current standard ones (singles, doubles, mixed)?
- Do Junior leagues require parent/guardian consent workflows during registration?

## Skill Levels
- How strictly are skill levels enforced? E.g., Can a 3.0 player register for a 4.0 league if there are spots left?

## Player Profiles
- Do player profiles need to display historical statistics or rankings publicly?
- Are players allowed to change their NTRP rating manually, or does an admin need to approve it?

## Registration
- Are there waitlists for leagues that are full?
- What is the cancellation and refund policy if a player withdraws before the season starts?

## Payment
- Will there be a need for subscription-based payments, or is it strictly one-time per league?
- Should the platform support promo codes, early bird discounts, or group rates?

## Matches/Scoring
- Do players self-report scores, or is an organizer responsible for inputting all match results?
- Is there a specific scoring format (e.g., best of 3 sets, pro set, ad/no-ad) that needs to be displayed?

## Rankings
- How are standings calculated (e.g., points per win, set differential)?
- Are tie-breakers handled automatically by the system?

## Organizer/Admin
- Who is responsible for initially publishing a league?
- Can an organizer send bulk emails/notifications to players in a league?

## Marketing
- Are there specific SEO requirements for league pages so they can be discovered via Google?
- Will the platform need to integrate with external marketing tools (e.g., Mailchimp, analytics)?

## "Dynamic" requirements
- Are match schedules generated dynamically based on player availability?
- Will the dashboard need real-time notifications for match updates or weather delays?

## "Attractive" design expectations
- Are there specific branding guidelines beyond the current color palette?
- Should we incorporate more video content or interactive court maps for venues?

## Reference websites
- Are there any competitor platforms or apps (e.g., USTA, Universal Tennis) that the client loves or hates?
