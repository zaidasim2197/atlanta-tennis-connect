## 1. Classification & Safety Rule

A league is classified as **SAFE TO REMOVE** if and only if:
1. It carries a demo/placeholder slug or pattern (e.g. `demo-league-*`).
2. All attached reservations have `paymentProvider: "mock"` with NO Stripe Payment Intent (`pi_*`).
3. None of its reservations belong to real human accounts (only synthetic accounts like `@demo.example.test`).

A league is classified as **BLOCKED (MUST NOT DELETE)** if:
1. Any reservation attached to it is backed by Stripe (`paymentProvider: "stripe"` or `pi_*`).
2. Any reservation belongs to a real human account or the showcase demo accounts (`p-demo-player`, `organizer@baselineatl.com`).
3. Deleting it would break active production tests or delete real user data.
