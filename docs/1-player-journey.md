# Player Journey

This document outlines the intended player journey for the Atlanta Tennis Connect platform.

## 1. Discover platform
- **Action**: User arrives on the Home page or via a marketing link.
- **Information needed**: Value proposition, what the platform is, formats available, upcoming seasons.

## 2. Browse leagues
- **Action**: User navigates to the "Browse Leagues" page.
- **Information needed**: List of available leagues.

## 3. Filter/search
- **Action**: User filters by Season, Skill Level, Format, Location (if applicable).
- **Information needed**: Clear categories for skill levels (e.g., 2.5, 3.0, 3.5), formats (singles, doubles, mixed). 
- *UNKNOWN*: Are there any specific search ranking requirements?

## 4. Select league
- **Action**: User clicks on a specific league card to view details.
- **Information needed**: Basic league summary, venue, schedule.

## 5. Review league information
- **Action**: User reads the full league description.
- **Information needed**: League name, season, format, age group, skill level, location, dates, registration fee, available spots, rules.
- *UNKNOWN*: Are there specific cancellation/refund policies that need to be displayed?

## 6. Register
- **Action**: User clicks "Register" and fills in their information (if not already logged in, they may be prompted to log in or create a profile).
- **Information needed**: Player's name, email, phone, skill level.

## 7. Mock payment
- **Action**: User enters payment information.
- **Information needed**: Credit card details, billing zip, amount to be charged.
- *UNKNOWN*: What actual payment gateway will be used? Will there be discounts or promo codes?

## 8. Registration confirmation
- **Action**: User completes payment and sees a success screen.
- **Information needed**: Confirmation number, next steps, receipt.

## 9. Player dashboard
- **Action**: User goes to their dashboard.
- **Information needed**: Upcoming matches, current leagues, past results, profile information.
- *UNKNOWN*: Do players schedule their own matches, or is there a fixed schedule?
- *UNKNOWN*: How do players report scores?
